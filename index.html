إعدادات مشروع Firebase الخاص بك

الموقع مربوط تلقائياً بمشروعك pattern-8ba7c. لكي يعمل التسجيل والرسائل والصور بدون أي قيود، تأكد من تفعيل التالي في لوحة Firebase:

1. تفعيل تسجيل الدخول (Authentication):

اذهب إلى Build > Authentication > Sign-in method وقم بتفعيل خيار Email/Password.

وفي تبويب Settings > Authorized domains أضف رابط موقعك على GitHub (مثل username.github.io).

2. تفعيل قاعدة البيانات (Firestore Database):

أنشئ قاعدة بيانات Firestore واجعل القواعد (Rules) تسمح بالقراءة والكتابة للمسجلين:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

3. تفعيل التخزين للصور والصوت (Storage):

فعّل Storage (وحتى لو لم تفعّله، الموقع يدعم إرسال الصور والصوت مباشرة كنسخة احتياطية ذكية!).
